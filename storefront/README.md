# Jatis Mutis — Tienda digital (concepto)

Esta carpeta contiene una propuesta independiente de storefront para la marca Jatis Mutis.

## Alcance de esta versión
- Landing page responsive y mobile-first.
- Catálogo visual de productos destacados.
- Filtros por categoría.
- Selección de productos y preparación de consulta por WhatsApp.
- Precios visibles únicamente para productos cuyos valores estaban publicados en la tienda vigente al momento de preparar el concepto.

## Importante
Esta es una demostración visual. No procesa pagos, no consulta inventario, no confirma disponibilidad y no reemplaza ni modifica Shopify. Antes de usarla comercialmente se deben validar catálogo, fotografías, textos, precios, datos de contacto, despacho, políticas y medios de pago con el titular de la marca.

## Publicación
Proyecto Vercel separado, con raíz de proyecto storefront/, para mantener aislado el panel interno existente.
